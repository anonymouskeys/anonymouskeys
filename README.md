## Our mission

The Internet should be open and accessible to everyone.

**Anonymous Keys** develops and maintains tools that help users access information, communicate freely, and overcome network restrictions. Our projects focus on practical anti-censorship technologies, Android networking clients, VPN subscriptions, and open-source development.

## Quick start

### Get a VPN subscription

Open the main subscription repository:

**[github.com/anonymouskeys/Vpn](https://github.com/anonymouskeys/Vpn)**

Choose either the plain-text or Base64 subscription link, then add it to a compatible client.

### Download an Android client

Visit the releases page of the required project:

- [Anonymous Keys DPI releases](https://github.com/anonymouskeys/Project-X/releases)
- [Monster VPN releases](https://github.com/anonymouskeys/Monster-VPN/releases)

Only install applications from official Anonymous Keys repositories and release pages.

## Principles

**Privacy first**  
We aim to build tools that respect users and avoid unnecessary data collection.

**Open Internet**  
Access to information should not depend on borders, censorship systems, or political restrictions.

**Open source**  
Public code enables review, learning, collaboration, and long-term project continuity.

**Practical technology**  
Our focus is on tools that are useful in real networks and understandable to everyday users.

**Community driven**  
Feedback, testing, stars, issue reports, and contributions help every project improve.

## Contributing

Contributions are welcome across the Anonymous Keys ecosystem.

You can help by:

- reporting reproducible bugs;
- improving documentation and translations;
- testing releases on restricted networks;
- suggesting usability improvements;
- contributing code through pull requests;
- starring repositories and sharing the projects.

For project-specific development information, open the repository you want to contribute to and review its README, issues, and contribution guidelines.

---

## Security and responsible use

Anonymous Keys tools are intended for privacy, interoperability, research, and access to information.

Users are responsible for complying with the laws and regulations that apply in their location. No networking tool can guarantee complete anonymity, uninterrupted access, or protection against every threat.
